# Исследование 4PDA

Систематизированная информация из форума 4PDA по FM350-GL и NC2312.

## 📂 Структура

- **fm350_main_thread/** - Основная ветка по FM350-GL
- **nc2312_thread/** - Ветка по адаптеру NC2312
- **solutions_database/** - База решений проблем

## 📝 Методология сбора

1. регулярный мониторинг веток
2. фиксация работающих решений
3. тегирование по категориям
4. кросс-референсы между постами
