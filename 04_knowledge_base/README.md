# Knowledge Base

Структурированная база знаний по модему FM350-GL: AT-команды, режимы USB, жизненный цикл, решение проблем.

## 📁 Структура

- **at_commands/** – справоцник по AT-командам
- **troubleshooting/** – решение типичных проблем
- **usb_modes/** – описание режимов USB (MBIM, QMI, RNDIS, ECM)
- **lifecycle/** – жизненный цикл устройства: загрузка, работа, выключение

## 🧠 Задача раздела

Собрать систематизированные технические знания, необходимые для диагностики, настройки и повседневной работы с модемом.

## 🔎 Как использовать

1. Используйте at_commands/ для поиска нужной команды
2. При возникновении проблем смотрите troubleshooting/
3. Для настройки режима связи смотрите usb_modes/
4. Для понимания поведения при вкл/выкл смотрите lifecycle/
