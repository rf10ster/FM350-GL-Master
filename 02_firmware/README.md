# База прошивок FM350-GL

Документация версий прошивок, инструменты обновления, резервные копии.

## 📂 Структура

- **comparison/** - сравнение версий
- **tools/** - инструменты для обновления
- **backups/** - резервные копии текущих прошивок
- **files/official/** - официальные прошивки
- **files/custom/** - кастомные прошивки
- **guides/** - руководства по обновлению

## ⚠️ Важно

- всегда делайте резервную копию перед обновлением
- проверяйте контрольные суммы файлов
- используйте официальные прошивки когда возможно

## 🔧 Процесс обновления

1. Проверка текущей версии
2. Резервное копирование
3. Подготовка файлов
4. Обновление через fastboot/adb
5. Валидация после обновления
