# Community

Материалы сообщества: полезные ссылки, посты и готовые решения из внешних источников.

## 📁 Структура

- **4pda_posts/** – выдержки и ссылки на важные сообщения с 4pda
- **github_gists/** – полезные скрипты и гисты от сообщества

## 🌐 Назначение

Раздел собирает полезные материалы из внешних источников (форумы, GitHub) для быстрого доступа и ссылок при работе с FM350-GL.

## 🔗 Рекомендации

- указывайте источник и автора при добавлении материала
- проверяйте актуальность ссылок периодически
- старайтесь сохранять локальные копии важных материалов на случай исчезновения оригинала
